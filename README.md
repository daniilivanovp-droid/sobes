# Собес.Тренер

Сайт для подготовки к собеседованиям: загружаете вопросы с эталонными ответами, отвечаете текстом или голосом и проверяете себя. Можно сразу посмотреть эталон или получить оценку и разбор от ИИ, как от интервьюера.

## Что есть

- Лендинг с описанием сервиса (`/`).
- Регистрация и вход по email и паролю, у каждого пользователя свои вопросы и попытки.
- Вопросы: добавление по одному, загрузка списком (текст или .txt/.md файл), редактирование, удаление.
- Тренировка (`/practice`): все вопросы по кругу, сначала новые, потом те, что повторяли давнее всего. Просмотр эталона тоже считается повторением.
- Ответ текстом или голосом (распознавание речи в браузере, работает в Chrome, Edge, Safari).
- Два способа проверки: «Показать эталон» сразу показывает эталон рядом с вашим ответом, «Проверить ИИ» ставит оценку из 10 и даёт разбор: что хорошо, чего не хватило, ошибки, уточняющий вопрос.
- История попыток по каждому вопросу.

## Запуск на своём компьютере

### 1. Подготовка (один раз)

1. Установите Node.js 20 или новее: https://nodejs.org (кнопка LTS).
2. Скачайте проект и перейдите в его папку:
   ```bash
   cd ~/Desktop
   git clone https://github.com/daniilivanovp-droid/sobes.git
   cd sobes
   ```
3. (Если `git` не установлен, macOS сама предложит поставить инструменты разработчика, согласитесь.)
4. Установите зависимости:
   ```bash
   npm install
   ```
   Предупреждения `npm audit` и `deprecated` можно не трогать.
5. Создайте файл настроек `.env` из шаблона и задайте секрет для входа:
   ```bash
   cp .env.example .env
   sed -i '' "s/change-me-to-a-long-random-string/$(openssl rand -hex 32)/" .env
   ```
   (На Linux команда `sed -i` без `''`.)
6. Создайте базу данных:
   ```bash
   npx prisma migrate deploy
   ```

### 2. Подключите ИИ для проверки (рекомендуется Groq)

Groq бесплатный и быстрый, проверка занимает несколько секунд.

1. Зарегистрируйтесь на https://console.groq.com (карта не нужна).
2. Откройте https://console.groq.com/keys, нажмите **Create API Key**, скопируйте ключ (начинается с `gsk_`).
3. Откройте файл `.env` в любом редакторе (например `open -e .env`) и вставьте ключ:
   ```
   GROQ_API_KEY=gsk_ваш_ключ
   ```
   Строку `GRADER=` оставьте пустой или впишите `GRADER=groq`.

Бесплатный лимит Groq: 30 проверок в минуту и около 1000 в день. На бесплатном тарифе провайдер может использовать запросы для улучшения своих сервисов, не загружайте туда ничего секретного.

Другие варианты в `.env`:
- `GRADER=ollama`: локальная модель через Ollama (бесплатно, без интернета, медленнее). Нужны `brew install ollama`, `brew services start ollama`, `ollama pull qwen3:8b`.
- `GRADER=claude` и `ANTHROPIC_API_KEY`: Claude API (платно, ключ на https://console.anthropic.com).
- `GRADER=openai` и `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`: любой OpenAI-совместимый API (OpenRouter, Mistral и т.п.).
- Без ИИ сайт тоже работает: «Показать эталон» доступен всегда, а проверка будет упрощённой.

### 3. Запуск

```bash
npm run dev
```

Откройте http://localhost:3000, зарегистрируйтесь и добавьте вопросы в разделе «Мои вопросы». Остановить сайт: Ctrl+C в Терминале. После изменения `.env` сайт нужно перезапустить.

### Обновление до новой версии

Остановите сайт (Ctrl+C) и выполните в папке проекта:
```bash
npm run update
npm run dev
```
`npm run update` скачивает свежую версию из GitHub, ставит новые зависимости и обновляет базу. Файл `.env` и база `prisma/dev.db` не затрагиваются.

## Формат загрузки списком

```
Чем let отличается от var?
let имеет блочную область видимости, var функциональную.
---
Что такое замыкание?
Функция вместе с лексическим окружением, в котором она была создана.
```

Первая строка блока это вопрос, остальное эталонный ответ, блоки разделяются строкой `---`.

## Проверка точности оценки

`npm run eval:grader` прогоняет 30 ответов из `eval/grader-cases.json` (6 вопросов, по 5 ответов разного качества с ручной оценкой) через выбранный в `.env` способ проверки и показывает, насколько его оценки совпадают с ручными. Чтобы сравнить способы, задайте его прямо в команде, например `GRADER=groq npm run eval:grader`.

## Стек

Next.js 15 (App Router, TypeScript), Tailwind CSS, Prisma + SQLite, сессии в подписанной httpOnly cookie (jose), пароли через bcrypt. Проверка ответов: Groq или другой OpenAI-совместимый API, Claude (`@anthropic-ai/sdk`) или Ollama.
